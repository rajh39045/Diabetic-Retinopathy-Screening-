
RETINA-XAI WINDOWS STARTUP
==========================

Run the setup commands once from the project root in PowerShell:

cd "C:\Users\vu241\OneDrive\Desktop\Diabetic-Retinopathy-Screening"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
cd frontend
npm install
cd ..

Create and configure backend\.env before starting the backend. It must contain
your MongoDB URI and a strong JWT_SECRET.


BACKEND - TERMINAL 1
--------------------
cd "C:\Users\vu241\OneDrive\Desktop\Diabetic-Retinopathy-Screening\backend"
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --port 8000

Backend URL: http://localhost:8000
Backend health: http://localhost:8000/health


STANDALONE AI API - TERMINAL 2
------------------------------
cd "C:\Users\vu241\OneDrive\Desktop\Diabetic-Retinopathy-Screening"
.\.venv\Scripts\Activate.ps1
uvicorn api.main:app --reload --port 8001

AI API URL: http://localhost:8001
AI API health: http://localhost:8001/api/health


FRONTEND - TERMINAL 3
---------------------
cd "C:\Users\vu241\OneDrive\Desktop\Diabetic-Retinopathy-Screening\frontend"
npm run dev

Open http://localhost:5173

The frontend uses the backend on port 8000 by default. The standalone AI API
on port 8001 is available separately at /api/screening/predict.
